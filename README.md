 # 🔐Password Validator Program

 ## 📌Project Overview
 This project is a **Password Validation Program** that checks whether a password meets the predifined security criteria.
 It helps users create **strong and secure passwords** by validating length, character types, and overall strength.

 This program is beginner-friendly and commonly used in **authentication systems**, **form validations**, and **security-related applications**.
 
 ---

 ## 🎯Objectives
 - Validate user-entered passwords.
 - Improve password security awareness.
 - Practice conditional logic and string handling.
 - Understand basic security rules in programming.

---

- **Language:** Python
- **Concepts:**
  -  Conditional Statements
  -  String Operations
  -  Loops
  -  Functions

---

## ✅Password Validation Rules
A Password is considered **valid** if it satisfies all the following conditions:

- Minimum **8 characters**
- At least **1 Uppercase letter**
- At least **1 Lowercase Letter**
- At least **1 Digit**
- At least **1 special character** ('@, #, $, %, &, !, *')
- No Spaces allowed
